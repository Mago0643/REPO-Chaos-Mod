# Log Location

Starting with version 2.0, this mod includes a feature that saves logs containing output from the mod itself.

The location of the log file depends on how you installed the mod.

### A. Thunderstore Mod Manager
1. Open **Settings** from the left-hand menu.
2. Under the **Directories** section, find **Profile folder** and click the **Browse** button.
3. A folder will open. Navigate to `BepInEx > plugins > Lego0_77-ChaosMod`.
4. The log file is named `latest.log`.

### B. Manual Installation
1. If you installed the mod manually, you should already know where the mod's folder is located, right?
2. If you don't, right-click **R.E.P.O.** in Steam, then select **Manage > Browse local files**.
3. Navigate to `BepInEx > plugins > Lego0_77-ChaosMod`
4. The log file is named `latest.log`
